# Task 1: House Price Prediction
## Objective
Build a machine learning model to predict house prices based on property features.
## Tools Used
* Python
* Pandas
* NumPy
* Scikit-Learn
## Models Implemented
* Linear Regression
* Random Forest Regressor
## Results
* Best Model: **Linear Regression**
* R² Score: **65.29%**
* MAE: **970,043.40**
## Conclusion
The model successfully predicts house prices and identifies area, amenities, and location-related features as the most important factors influencing property value.
